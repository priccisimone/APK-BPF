# Organigramma BPF
App Android offline, senza permessi Internet, con albero completo sempre visibile, ricerca per nome/cognome e percorso gerarchico evidenziato.

## Compilazione dal browser con GitHub
1. Crea un repository GitHub privato.
2. Carica tutto il contenuto di questa cartella nella radice del repository.
3. Apri Actions > Build APK > Run workflow.
4. A fine esecuzione scarica l'artifact BPF-Organigramma-APK e installa app-debug.apk sul telefono.

## Nota dati
Fonte organizzativa: documento BPF del 01/10/2026, pagine 5 e 6. I nomi completi sono stati ricavati dall'elenco destinatari della comunicazione aziendale del 02/10/2026 quando disponibili. L'app e i dati restano interamente offline.
